# Rampage

**<Toast> has just FOUR MORE BOSSES!** A cooperative monster-and-city-smashing minigame for TBC Classic 2.5.6 raid downtime. Inspired by classic climb-and-smash arcade play; original geometric art and fictional encounters, not affiliated with the original Rampage game or its owners.

## Status
Initial scaffold. First playable MVP is being implemented on a feature branch; see PLAN.md. CurseForge publication is deliberately deferred.

## Install
Copy the `Rampage` folder into `World of Warcraft/_anniversary_/Interface/AddOns/` and enable it at character selection. `/rampage` opens the addon. Development checkout: `C:\Users\leroy\repos\Rampage`.

Repository: https://github.com/lemillermicrosoft/Rampage
